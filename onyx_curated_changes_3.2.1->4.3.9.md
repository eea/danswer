# Onyx – Curated Changes & Improvements (v3.2.1 → v4.3.9)

A curated compilation of meaningful improvements, day-to-day user features, and administrator configuration options between versions **3.2.1** and **4.3.9**. Enterprise-specific features and complex technical jargon have been omitted in favor of clear, practical explanations.

---

## 👤 Features & Improvements for End Users

- **Full-Width Chat Mode** ([`0cd6df5eed`](https://github.com/onyx-dot-app/onyx/commit/0cd6df5eed927f7b3476de0ee1168dbb66c9bad1)) — Expand your conversation window to the full width of your screen at any time, giving plenty of room for wide tables, spreadsheets, and longer responses.
- **In-Chat Excel Spreadsheet Previews** ([`bcdc7fe183`](https://github.com/onyx-dot-app/onyx/commit/bcdc7fe183e49743b6e6a7062153345b45d0e771)) — View Excel spreadsheets (`.xlsx`) attached to conversations directly inside the chat interface without having to download and open them separately.
- **Dynamic Browser Tab Titles** ([`fcc9044b48`](https://github.com/onyx-dot-app/onyx/commit/fcc9044b485deff62f4e1396c17b2126bd5ff5e9)) — Your browser tabs now display the title of your current chat conversation or search query, making it easy to find specific conversations among multiple open tabs.
- **Automatic Draft Saving** ([`02d6754029`](https://github.com/onyx-dot-app/onyx/commit/02d675402918df7830bcb3c7449ea1e2bbe26f2b)) — Never lose what you've typed: unfinished messages and custom assistant prompts are automatically saved in the input box if you navigate away.
- **Filter Search by App in the UI** ([`123194d543`](https://github.com/onyx-dot-app/onyx/commit/123194d543efb9d1c8f6d6920139391982c4a644)) — Pick and choose which connected applications (like Slack, Google Drive, or Confluence) you want to search across using convenient filters right inside the search bar.
- **Side-by-Side Model Comparisons in Shared Chats** ([`da94192d6a`](https://github.com/onyx-dot-app/onyx/commit/da94192d6a45066a3809460a9b29a7b3ddc989dc)) — Compare answers from different AI models side by side, and share those side-by-side comparison links with your colleagues.
- **High-Resolution Image Generation** ([`7c93500c91`](https://github.com/onyx-dot-app/onyx/commit/7c93500c91e7800db8140f9a14365cb969e6fc21)) — Generate detailed AI images directly inside your chat conversations using Google Gemini 3 Pro.
- **Cleaner Tables & Syntax Highlighting** ([`0971302e16`](https://github.com/onyx-dot-app/onyx/commit/0971302e169bff26ec84fefdc35fd4534d60a915)) — Formatted tables in chat responses now scroll horizontally when wide without breaking page layout, and code snippets feature clean syntax highlighting across all programming languages.
- **Direct Actions in Connected Apps** ([`a2b11208b4`](https://github.com/onyx-dot-app/onyx/commit/a2b11208b47394674290062cfdb363bccc00c9ff), [`71b37a5639`](https://github.com/onyx-dot-app/onyx/commit/71b37a5639b7bb221b6a78280dd94c48971f16fa)) — Authorized assistants can now interact directly with connected tools like editing Google Docs or finding records across connected apps with your confirmation.
- **Redesigned Notification Center** ([`66ac4a43bc`](https://github.com/onyx-dot-app/onyx/commit/66ac4a43bc1192437d4cc607aef975ddb805a7c5), [`86215ddb6b`](https://github.com/onyx-dot-app/onyx/commit/86215ddb6b9b029f9ec39446ed323ee304639171)) — A clean notifications center that separates new notifications from older ones, with smooth pagination so active users don't experience sluggish loading.
- **Buttery-Smooth Chat Streaming** ([`bf30f2a768`](https://github.com/onyx-dot-app/onyx/commit/bf30f2a768a2c0ae26e22330c9579ee1a6f555c0)) — Incoming responses now stream word-by-word with fluid, stutter-free animations.
- **Smart Google Drive Document Links** ([`0fa8f23334`](https://github.com/onyx-dot-app/onyx/commit/0fa8f2333451abab8c809b29689e0b9032344efa)) — Search results from Google Drive now resolve directly to the active document without broken links or permission redirects.
- **Consistent Prompt Placeholders** ([`1da679cefc`](https://github.com/onyx-dot-app/onyx/commit/1da679cefc96165c6b9b64c3bc769584b88f88c2)) — Dynamic values like current date, username, and context now resolve reliably across all custom prompts and agent templates.
- **Voice Input Silence Filtering** ([`55bd1ed6b6`](https://github.com/onyx-dot-app/onyx/commit/55bd1ed6b6b233873a96f155608f15f06b8e5fe9)) — Voice recording automatically filters out silent pauses so voice-to-text doesn't generate hallucinated phantom words.
- **Knowledge Pane Search** ([`c8ba005da7`](https://github.com/onyx-dot-app/onyx/commit/c8ba005da719ad880afbff08b067241eb3f9adc1)) — Search and explore connected knowledge base documents directly inside the assistant configuration and side panel.
- **Clear Usage & Rate Limit Guidance** ([`67b7d115db`](https://github.com/onyx-dot-app/onyx/commit/67b7d115db599d21d67b9896d990c885848558b8)) — If you reach your daily token or message limit, you'll see a clean, informative popup explaining when your quota resets.
- **Reliable One-Click Copying** ([`bb1c44daff`](https://github.com/onyx-dot-app/onyx/commit/bb1c44daff1e74e390838318b6851cf20d25df16)) — Added fallback copy support for restrictive browsers and environments where standard clipboard shortcuts are blocked.
- **Direct Folder & Section Links** ([`06f586a2d8`](https://github.com/onyx-dot-app/onyx/commit/06f586a2d8af114cc07754de4478e789a931c658)) — You can now copy direct links to specific folders or sections in the document sidebar, making it effortless to share exact document locations with your teammates.
